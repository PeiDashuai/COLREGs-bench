# Benchmark Generation and Validation Code

This directory contains the final generator, labeler, acceptance, rendering, and
release-building implementation for the four encounter families. It contains no
candidate pools, snapshots, historical releases, or generated reports.

The distributed `COLREGs-Bench-final` asset is immutable. Run this code only in
a new work directory; do not point a generator or labeler at the extracted final
release.

## Work-directory layout

The scripts use the following relative locations under `--root`:

```text
config/
schemas/
raw_pool/<family>/
annotated_pool/<family>/
accepted_pool/<family>/
release/
reports/
```

The public `config/` and `schemas/` directories in this folder are the starting
point for a new work directory. The generation chain is:

1. validate the four generator specifications;
2. generate one raw pool per encounter family;
3. apply the corresponding deterministic labeler and validator;
4. annotate generation metadata and apply family acceptance checks;
5. render top-down and radar-style images;
6. construct fixed train/validation/test splits;
7. run structured-label and duplicate audits.

Each script provides its exact command-line arguments through `--help`. The
family-specific implementation files are intentionally explicit so that their
acceptance conditions can be inspected without a hidden routing layer.

The expert-corrected test reference is a post-generation evaluation asset. It is
distributed only in `COLREGs-Bench-final/evaluation/expert_corrected_core3/` and
is not regenerated by these scripts.
